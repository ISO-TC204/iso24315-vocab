# traffic regulation order

<div class="draft4-watermark" aria-hidden="true"></div>

legally recognized document that officially specifies one or more [regulations](regulation.md)

<object type="image/svg+xml" data="../../diagrams/traffic regulation order.dot.svg">
    <img alt="traffic regulation order Diagram" src="../../diagrams/traffic regulation order.dot.png" /> <!-- Fallback for non-SVG browsers -->
</object>

Clause: 3.2.1.14

Admitted term: TRO

Note 1 to entry: A traffic regulation order can be associated with meta-data that activates or de-activates all or some of the regulations defined within the order. For example, a [rule maker](rule maker.md) can define an order containing multiple regulations that can be made [active](active rule.md) or [inactive](inactive rule.md) as a single unit.

History note: 2026: Revised to align with the updated definitions for [rule](rule.md) and [regulation](regulation.md).
